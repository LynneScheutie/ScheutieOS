光合作用核心要点

光合作用可拆成两个阶段，分别在类囊体薄膜和叶绿体基质中进行。

  • 光反应：水的光解产生 O₂、NADPH 和 ATP
  • 暗反应：CO₂ 被固定为三碳糖，消耗 ATP 与 NADPH
  • 总反应式：6CO₂ + 12H₂O → C₆H₁₂O₆ + 6O₂ + 6H₂O

示例代码：

def atp_yield(photons):
    """每 8 个光子约产生 3 个 ATP"""
    return photons // 8 * 3

print(atp_yield(64))  # 24
